# Foddy

Aplicación web instalable (PWA) para planificar los menús semanales de una niña de 2 a 3 años a partir del menú del colegio.

- Solo cenas de lunes a viernes con colegio; comida y cena en fines de semana y festivos.
- Tope diario de proteína animal configurable, prioridad de proteína vegetal en la cena si la comida lleva proteína animal, fruta y verdura de temporada, sin ultraprocesados ni azúcares.
- Usa Claude Sonnet 5.5 con la clave de API de la propia usuaria, que se guarda solo en el dispositivo.
- Sin servidor propio: archivos estáticos publicados con GitHub Pages.

Los datos (ajustes, platos modelo, último menú y clave) se guardan en el almacenamiento local del dispositivo. No hay base de datos ni cuentas.
